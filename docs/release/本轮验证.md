## 发布检查

沿原发布清单构建独立目录，排除个人.local配置、存档、日志、备份和完整EPUB。仅从开发版检索缓存带入审核通过的423条原文参考、向量和固定模型；作者本机路径脱敏。继承项目的第三方默认代理清空，用户自行配置API。

随包Node与v0.2二进制相同，保留许可证。模型词表中的Administrator是固定词项，不是个人配置，不能删掉。清单和ZIP完整性、包内启动及HTTP资源、本地禁网检索、GitHub源码与附件摘要均另行核验后发布。

本轮不调用用户API、不操作正式存档，不重新做浏览器试玩，也不把HTTP资源核验视为页面验收。真实模型写作、复杂语义条件、界面体验仍待作者测试。既有5项原著语义检索命中问题保留，未修改期望或宣称已修。脱敏检查不等于对全部历史代码和第三方依赖作全面安全认证。

两个测试版本使用同一8090地址。升级前导出存档并退出旧版；同一浏览器可能保留原进度。API连接属于各个目录，新版需要时重新配置。
