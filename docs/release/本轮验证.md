## 下载与启动

Windows 10/11 x64。下载本发布页附件 `Joffreys-Decision-v0.4-win-x64.zip`，完整解压后双击「启动游戏.cmd」。已带 Node、运行依赖、像素素材、423条审定原著参考与本地检索模型，无需另外安装 Node。GitHub 的 Source code 压缩包不含完整运行依赖。

默认地址仍为 `http://127.0.0.1:8090/`。启动和本地检索不调用付费模型；自由交流须在游戏设置中配置自己的 API。本包不含作者连接、密钥、预设或玩家存档。背景音乐保留接入接口，未附私人音乐资源。

## 相对 v0.3 的变化

- **通用改革**：方向建议可形成有负责人、范围、预算、阶段和依赖的合同；包含时代评估、暂停、修订、检查点、周会汇报及近卫转达求见。核心流程仍是玩家提出方向、大臣报价、玩家批准后实际执行。
- **财政、军事、情报、行政**：12个方向已有有限真实执行入口，包括合同扣缴、已实收新债偿还旧本金、附条件专项资助、军械工坊、训练换装与供饷、具体岗位与密道安保、付费港口观察、书记员及账户/军籍核查。
- **人物 V2**：普通对话、会议及后台任务共享本人上下文；局部属性与关系变化须有依据并写回经历；新抓捕在送达后程序即时接令。原人设、分层记忆和异步 Post 恢复机制保留。
- **抓捕与拘押**：送达、查找、控制、押送、看管、释放分开执行，并影响出席和工作。相关逃逸与终章限制见页首。

修复了此前审查确认的8项问题：旧工程与工坊重复占用工班；审批条款遗漏及对象显示异常；合法专项资金不能自动付款；还本/服务续费漏扣缴及重复风险；旧核账漏计扣缴实收；抓捕缓存遗漏已送达的供饷报告；默认人物资料误算为态度变化经历；港口续费补报停费期间到货。

## 升级与存档

1. 升级前在旧版导出存档，并从「设置 → 退出游戏」结束旧服务。
2. 将 v0.4 解压到新目录，不覆盖旧版本。两个测试版均使用8090；同一浏览器可能沿用原进度。
3. API连接属于各自目录，新目录未配置时请重新设置。不要把个人 `.local` 配置转发或上传。

兼容字段按现有规则读取，人物新增资料缺失时使用默认补读，不回算历史。导入会产生新分支。已生效改革不重算，旧试办服务不会暗中获得持续扣费授权；缺少财务条款的未批准旧报价可能须重新澄清。未验证所有历史玩家存档，也不承诺使用新机制后的存档能够退回 v0.3。
