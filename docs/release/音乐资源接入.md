# 背景音乐资源接口

播放器直接使用姬侠传 module/bgm-manager.js。权游 module/got/music.mjs 只根据真实地点、时间和当前剧情挑选曲目，并提供设置开关与音量。没有新增模型调用，没有随正文猜测场景。

1. 把音频放入 assets/got/music，可以使用子文件夹。支持浏览器能解码的 mp3、ogg、wav、m4a。
2. 修改同目录 catalog.json，把空字符串替换为相对路径，例如 "court.mp3" 或 "court/day.mp3"。空项不加载文件。
3. 刷新页面，打开「设置 → 背景音乐」。浏览器首次播放可能需要先点击页面。

选择顺序：专用剧情 → 具体房间 → 大区域时段 → 默认曲目。没有配置则安静，不反复请求不存在的音频。同一曲目不会因翻页、点击或重新渲染从头播放。音乐不影响游戏时间或政治数据。

- contexts.council：御前会议；blackwater：黑水河战斗及结果；finale：终章。
- regions：Z01红堡、Z02伊耿高丘、Z03维桑尼亚丘、Z04雷妮丝丘与东侧、Z05西侧市街、Z06河门港区、Z07跳蚤窝。每项有day/dusk/night。
- places：可填现有小场景编号，例如 "R01": {"day":"bedroom.mp3","night":"quiet.mp3"}。场景编号沿原地图，不在这里建立新场景。
- 时段：06:00—17:00白天，17:00—20:00黄昏，其余夜间。

示例：将default填为 "court.mp3"，contexts.council填为 "council.mp3"，即可先用两首曲目覆盖普通场景和会议。不需要逐地点填满。

本轮未收集、下载或分发任何音乐。设置中「已载入」仅说明文件已选择，实际听感与版权授权由后续用户资源验收。
