# 当前复用清单与后续

| 部分 | 正式运行来源 | 权游连接与区别 |
|---|---|---|
| 请求入口 | 姬侠传 module/api-service.js | 保留双连接快照与本机网关；不启用原武侠结算或失败自动重发 |
| 原生Gemini消息 | 同文件 jxGeminiBody，由原Gemini方法提取 | 原Gemini与权游原生Google请求调用同一个映射函数；正文与中间层均可使用 |
| Vertex服务账号 | SillyTavern 1.16.0 src/endpoints/google.js 的JWT/OAuth实现 | 改接现有本机凭据文件，增加本地校验、取消、内存令牌缓存和错误脱敏 |
| 配置界面 | 姬侠传 ui/config-modal.js | 原弹窗增加协议选择、JSON与地区字段；不另建配置系统 |
| 音乐播放 | 姬侠传 module/bgm-manager.js | music.mjs按真实地图、时段、会议、战斗、终章选曲；不随模型臆测切换。修正旧自动播放回调在关闭音乐后仍可能触发的问题 |
| 正文解析与阅读 | module/response-parser.js / game-ui.js | 原正文解析、分页和Markdown实现；保留完整小说正文、羊皮纸外观、单轮主要人物头像 |
| 提示词与历史 | ui/prompt-manager-modal.js / module/game-ui.js | 原编辑器与历史阅读器；权游只提供准许资料和正式记录 |
| 特殊事件通用条件 | module/special-event.js | 复用比较、完成过滤和链条筛选；权游仍检查真实在场、消息、时间与唯一结算 |
| 存储与记忆 | 继承的storage-service、IndexedDB、summary/embedding等模块 | 原存储与请求基础，权游接真实知情、分支隔离和本人记忆；本轮未重建 |

本目录是v0.2内部测试快照，开发维护继续在开发版进行。release-manifest.json记录本包文件的SHA-256。分发不含个人连接、存档、日志、开发备份或完整EPUB。

默认允许玩家使用自备API。当前修复沿用原有请求、提示词、会议、保存和唯一提交入口；后台整理、参数核对和知情连接是本次权游适配内容。参见本轮验证与更新记录。

背景音乐保留接入接口；自定义世界书、聊天JSONL导入及装备扩展不属于此次发布。真实模型表现继续由测试者试玩验证。
