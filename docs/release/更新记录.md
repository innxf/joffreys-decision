# 测试版v0.2

- 正文先保存并释放前台操作，普通对话、事件、多人用餐及会议的事后整理进入后台；失败不丢正文，不自动重复请求。
- 核对命令中的人物、数量、单位、对象、期限与条件；不把四十人误执行成二百人。含糊参数保留澄清，不开放任意改变量。
- 人物阶段读取有效事实与本人知情；补齐本人报告、经办任务和已传播事项。詹姆伤势须已有真实记录，不按原著日历自动制造。
- 散会材料按来源去重；默认前后置提示词精简，正文使用中文指导，人物专属规则按需加入，最终消息核对必要材料。
- 引用允许标点及合理分句，区分台词与旁白，保留条件及拒绝。背景人数与实际命令数量分别检查。
- 提案条件深拷贝，批次执行按编号取最新对象；流式状态检查只重算听众等必要内容。

保留原会议、人物、政治数值、剧情和终章。本版为内部测试预发布；v0.1继续保留。
