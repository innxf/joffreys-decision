# 乔佛里的决定

**Joffrey’s Decision · 测试版 v0.3**

Windows 10/11 x64。请下载 Releases 中的 `Joffreys-Decision-v0.3-win-x64.zip`，完整解压后双击「启动游戏.cmd」。浏览器自动打开，无需安装Node或手输网址。GitHub的Source code压缩包不含完整运行依赖。

## 本次更新

- 修复条件、旁白、人数和期限的引用误判，正确区分并列命令。
- 同一会议裁决的重复动作只执行一次；跨议题冲突指向相关议题澄清。
- 完整返回在恢复时复用，明确重新请求才调用模型；修复读档后的旧后台队列。
- 修复人物阶段误触发、执行判断与记忆整理的JSON处理，保留原有剧情和世界结算。

## 使用与升级

- 固定剧情可直接体验；自由交流在游戏「设置」中配置自己的API。本包没有作者密钥、个人连接或存档。
- 已包含本地运行环境、像素素材和原著向量参考；启动与本地检索不调用付费API。
- **升级前先导出存档，在旧版设置中退出游戏，再启动v0.3。**默认地址仍为 `http://127.0.0.1:8090/`，同一浏览器可能沿用原存档。
- API配置保存在各自文件夹的 `.local`；新版本没有连接时请重新配置。不要将个人配置加入公开包。
- 在游戏内保存与退出。背景音乐保留接入接口，未附私人音乐资源。

本版用于内部测试。检查范围及已知限制见 `docs/release/本轮验证.md`，第三方署名与许可见 `docs/third-party`。
