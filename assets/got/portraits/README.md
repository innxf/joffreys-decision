# 角色像素头像 V1

已制作 118 张。剧照参考 91 张；原著设定原创 27 张。

覆盖 P001—P115、U001，以及运行人物 R001 奥柏伦、R007 科本。保留原人物编号。每人一张，不含表情或服装差分。

采用统一深青背景、方形半身构图。输出为生成工具实际返回尺寸，未通过裁切或像素滤镜制作。参考剧照原文件、来源页和生成提示词保留；少数原著配角缺少确切脸部描述，原创补全已标记。

本批制作素材与图册，没有替换游戏人物资料、剧情、存档或现有头像显示逻辑。portrait-map.json 可供下一步按编号接入。未调用游戏正文或中间层 API。

剧照来源包括社区资料页、IMDb 图片、ThronesAPI 及图片转载页，不把转载页冒称 HBO 官方。原著外貌条目使用带章节定位的 A Wiki of Ice and Fire，造型补全属于本卡美术设计。

P083、P108、P111 有剧版角色，但未取得可用剧照，先交原创版；P052 的现有剧版远景不足以确认脸部。P075 克里奥不是剧版奥尔顿；P076 简妮不是塔莉莎；P080 瓦格不是洛克。
