# 乔佛里的决定

**Joffrey’s Decision · 测试版 v0.1**

内部测试版。Windows 10/11 x64，解压整个文件夹后双击「启动游戏.cmd」。浏览器会自动打开；不需要手输网址，不要直接打开HTML。

- 已包含本地运行环境、场景与头像，以及423条原著参考和本地向量检索。启动和检索不调用付费API。
- 固定剧情可直接体验。自由交谈需要在游戏「设置」中填写自己的API连接；本包不含任何作者密钥或个人存档。
- 在游戏内存档；退出用「设置 → 退出游戏」。个人连接保存在首次配置后生成的 `.local`，请勿上传或转发这个目录。
- 默认地址为 `http://127.0.0.1:8090/`，与开发版存档隔离。API需要自行配置，存档可通过界面导入、导出。

本版本用于收集流程、界面和模型扮演反馈；不代表所有剧情和真实模型表现已经验收。保留原系统与第三方组件署名，见 `docs/third-party`。背景音乐接口已保留，未附私人音乐资源。

GitHub 测试者请下载 Releases 中的 Windows 完整包；源码下载不包含随包运行环境与依赖。
