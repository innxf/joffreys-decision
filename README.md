# 乔佛里的决定

**Joffrey’s Decision · 测试版 v0.2**

Windows 10/11 x64。请下载 Releases 中的 `Joffreys-Decision-v0.2-win-x64.zip`，完整解压后双击「启动游戏.cmd」，浏览器会自动打开。源码下载不含运行环境与完整依赖。

## 这一版的变化

- 正文保存后即可继续交谈和移动，事后整理在后台处理；整理失败保留正文，可以在待办中恢复。
- 修复命令数量、对象、期限与原话不一致的检查，补齐人物经办事项和已送达信息的认知来源。
- 修复人物阶段、会议资料重复、预设漏传材料、引用误判、提案引用污染和流式重复计算等问题。
- 精简中间层提示词，保留完整人物基底和原有知情边界。

## 启动与存档

- 已包含本地运行环境、像素场景与头像、本地原著参考和向量模型。启动与本地检索不调用付费API。
- 固定剧情可直接体验。自由交谈请在「设置」填写自己的API；本包不含作者密钥、个人连接和存档。
- 存档和退出均在游戏内操作。个人配置会保存在 `.local`，请勿上传或转发这个目录。
- 默认使用 `http://127.0.0.1:8090/`。从v0.1升级前请先导出存档备份，并在旧版设置中退出游戏，再启动v0.2。相同浏览器与地址可能继续使用原浏览器存档，并不是新建一份隔离存档。
- API连接保存在各自文件夹；如新版本没有连接，请重新配置。不要把旧版个人配置加入公开发布包。

测试范围与已知限制见 `docs/release/本轮验证.md`。本轮没有调用真实模型；真实扮演质量仍需试玩。背景音乐保留接口，未附私人音乐资源。第三方署名及许可见 `docs/third-party`。
